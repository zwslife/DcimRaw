## 提交次序

1. 本人注册 vivo 国内开放平台账号并完成个人实名。
2. 在后台核验个人开发者是否接受本应用类别、版权材料、备案要求及素材规格；记录实际要求。
3. 补齐实名名称、版权证明及需要的备案材料，确认应用名称与材料主体一致。
4. 完成应用内隐私说明、政策网页和正式签名候选包，进行真机测试。
5. 用候选包拍摄真实截图，核对后台字段和 APK 的名称、包名、版本、图标及签名。
6. 上传材料，提交审核；根据审核结果修正后再次提交。
7. 以后台显示“已上架”且商店详情可访问、安装成功为完成依据。
