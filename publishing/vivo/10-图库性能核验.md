# 图库性能改动核验

日期：2026-10-25。候选包：0.9.17（41）。尚未上传 vivo，不代表真机验收或上架审核通过。

## 已改动的瓶颈

| 环节 | 原行为 | 当前行为 |
| --- | --- | --- |
| 系统相册扫描 | 在调用方主线程同步查询全部记录 | IO 线程读取，首批 32 条、后续每 512 条发布 |
| SAF 目录扫描 | 每个文件分别读取名称、类型、大小、时间 | 每目录一次查询取得所需字段，按批发布 |
| 索引刷新 | 扫描全部完成后清表再全量写入 | 已有列表可先显示；只写变化行；成功扫描后才删除消失的记录 |
| 扫描中断 | 原流程可能把不可读子目录当作空结果 | 不可读/仍加载的子目录使本次扫描失败，保留旧记录；目录切换取消并等待旧任务结束 |
| CR3 筛选 | 逐文件串行探测，内存缓存超过 512 条整体清空，重启失效 | 独立持久格式表；批量查询，最多 4 个并行文件头读取；按 URI/大小/修改时间失效；失败与未就绪文件允许重试 |
| 网格与日期 | 主线程日期分组，逐条注册整份网格 | 后台分组，可取消；网格按需创建，点击按 URI 定位 |
| CR3 预览 | 自定义模型无 Coil 内存缓存键，重复请求可能重复提取 | 加入文件版本缓存键，同一文件提取去重，最多两个并行提取 |
