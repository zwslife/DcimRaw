# 若图 Android 重构 · 开发定稿

以[已确认的交互设计稿](prototype-ios-v2.html)为视觉参考。原型尺寸按 Android `dp` 落地，文字用 `sp`。布局以内容区为准，状态栏和导航栏使用系统 insets。校对宽度为 320、360、390 dp，横屏和分屏时保留照片空间，参数区可滚动。

| 元素 | 开发规格 |
| --- | --- |
| 颜色 | 白色控件和面板 `#FFFFFF`，照片画布 `#E9EAEC`，分组底 `#EDF0F3`，正文 `#202124`，次要文字 `#656972`，主操作墨青 `#176753`，删除 `#B4232B` |
| 图标和触控 | 常规图标 18–19 dp，触控区通常 44 dp。编辑完成为 30 dp 墨青圆形对勾。窄屏时并排的小控件均分可用宽度 |
| 对比 | 仅在编辑页的调色和蒙版工具中显示，位于照片区域右下。44 dp 触控区内居中放 28 dp 方形底，圆角 5 dp，白色 80% 不透明度，18 dp 深灰分割线图标。按住显示未调色原图，松手或手势取消恢复 |
| 编辑面板 | 顶角 24 dp，标准高度约占可用编辑区 40%，曲线给画布更多高度。工具入口固定首行，参数可纵向滚动，窄屏工具入口保持单行 |
| 参数 | 同一行左侧显示名称、右侧显示值，下方放紧凑滑条，双向参数从中点、单向参数从左端显示调整段。曝光不附 EV。保留双击复位与无障碍滑条操作 |

| 场景 | Compose 实现与验收 |
| --- | --- |
| 图库 | `GridScreen` 标题栏放来源、选择和更多。来源菜单切换系统相册或已授权目录，可添加或更换授权目录。各来源始终显示全部已索引照片，授权目录可浏览 CR3 和常见位图格式。四列方形缩略图、2 dp 间距，仅 CR3 有 RAW 标识。滑动多选、全选、删除和选择计数在同一个选择流程中 |
| 预览 | `PhotoPagerScreen` 顶栏顺序为直方图、信息、更多，底栏为居中的编辑、导出、删除，约 176 dp。保留手势缩放、惯性、左右翻页，隐藏顶栏时照片位置稳定。信息为白色底部面板，直方图切换位于信息标题行 |
| 编辑 | `PhotoEditorScreen` 的顶栏为关闭、撤回、重做、更多、完成。面板首行用同一入口切换光线、曲线、色彩、混色、效果、分级、细节、蒙版和旋转裁切。关闭丢弃本次修改，完成持久化，撤回重做覆盖整次编辑。一次连续手势记作一步。编辑内全部复位覆盖调色、蒙版和裁切，预览中的调色复位覆盖调色与蒙版 |
| 曲线与混色 | RGB、红、绿、蓝与工具入口同行。曲线红绿蓝和混色共用 16 dp 实色色点，RGB 为三色实心圆，选中均在图内显示白色对勾。混色八通道各自保存 HSL。保留曲线端点水平拖动、中间点操作与各通道互补色提示 |
| 分级 | 阴影、中间调、高光、全局依次用月亮、半圆、太阳、光圈表示，与工具入口同行。仅当前图标加深为墨青并加粗，四个区域各自保存参数，混合与平衡为共享参数 |
| 蒙版 | 工具入口和范围/调整控制与蒙版条放在面板顶部。切换蒙版保留独立参数，新建在末尾，沿用现有画笔、线性和径向范围。蒙版调整支持光线、色彩、混色、效果、分级、细节。蒙版与照片同步缩放 |
| 裁切 | 工具入口同行放左右旋转图标，取消单独复位。旋转约 260 ms，从当前显示角度续转并适配照片区域，停稳后恢复裁切框。自由旋转用中线刻度尺，立即反馈，比例卡 52 dp，选中对勾显示于比例框内 |
| 导出与删除 | 白色底部面板。导出显示格式和尺寸，CR3 可选内嵌 JPEG。删除先做应用内二次确认，再沿用系统授权与实际删除结果。拒绝授权后保留图库项 |

发布验收覆盖 CR3 与常见系统相册格式、保存后重开、复制粘贴、全部复位含蒙版、跨工具撤回重做、旋转时裁切框、深浅照片上的按住对比，以及从系统相册删除后图库同步。
