# 若图 Android 界面重构交接稿

**开发基线**　0.9.23（47） · `34eb653d5c0184307bfe47756842799d1e3461ac` · Kotlin / Jetpack Compose · minSdk 26

## 1. 交付与范围

- [可交互原型](prototype.html) 可直接用浏览器打开。启动场景是红色曲线，便于核对画布和菜单。原型用于验证布局和交互，照片、数据和调节效果为示例。原型图标加载依赖网络，离线时可查看随包 PNG。
- [可编辑原型源文件](prototype.source.html) 保留完整页面样式和交互代码，可作为后续设计迭代的源稿。
- [截图索引](#7-截图索引) 提供 390 × 808 的界面参考。本稿中的 Android 尺寸、逻辑与验收条件是实现依据。
- 本轮交付覆盖图库、照片预览、独立编辑、照片信息、导出与删除。优先完成编辑工作区，再接入图库和预览的视觉调整。沿用现有 RAW 解码、图像处理、授权流程与 `PhotoEditStore` 格式。
- 本轮确定的编辑入口是**参数区顶部的统一下拉菜单**。移除编辑底部工具条、左下角浮动入口和常驻分类 Tab。预览底栏保留「编辑」「删除」「导出」。

## 2. 页面和流程

| 场景 | 从上到下的界面 | 交互与状态 |
| --- | --- | --- |
| 图库 | 大标题「照片」，右侧「选择」和更多；来源入口；过滤项；按日期分组的四列方形缩略图 | 点图进入预览，长按或点「选择」进入多选，继续支持滑动连续选择。刷新入口放进更多菜单，下拉刷新复用现有扫描回调。权限缺失、来源断开、空库、过滤无结果分别显示对应状态。 |
| 照片预览 | 返回、文件名、照片信息、更多；中性照片区；三项操作栏 | 单击照片显隐控件，双击缩放，放大后单指优先平移。编辑在图片解码完成后可用。更多入口保留其它实际可用的照片操作，调色复制、粘贴及复位进入编辑更多菜单。 |
| 独立编辑 | 左上 ×；右侧撤销、重做、更多、「完成」；照片工作区；参数区及统一菜单 | 从预览进入，同一会话可连续编辑调色、蒙版和旋转裁切。开关菜单不改变照片或参数区的布局。 |
| 照片信息 | 底部面板，显示文件信息、EXIF 与直方图开关 | 使用实际读取值。读取中显示进度，缺失字段用「—」或隐藏。关闭回到同一张照片。 |
| 导出 | 底部面板，格式选项、格式和尺寸摘要、「保存到相册」 | 默认「编辑后 JPEG」。CR3 可选「相机内嵌 JPEG」，提示「不应用编辑」。前者尺寸取 `PhotoGeometry.outputSize`，后者优先显示已取得的内嵌尺寸，未知时显示「机内预览尺寸」。结果显示真实成功或失败。 |
| 删除 | 底部面板，单张缩略图与文件名或批量张数、后果说明、红色「删除照片」、独立「取消」 | 先确认，再发起现有系统授权。拒绝时保留照片与索引；部分成功时只移除已删除项，按实际结果反馈。 |

图库过滤项按当前数据查询范围显示名称。若仍使用基线的 `cr3Only` 开关，文案用「仅 CR3」，原型中的「仅 RAW」用于示意布局。

## 3. 编辑工作区

### 3.1 会话和导航

| 动作 | 实现约定 |
| --- | --- |
| 首次进入一次编辑会话 | 等待已保存编辑加载完成，按当前 URI 建立基线和草稿。默认显示「调色 · 光线」。同一会话从其他工具回来时，恢复之前的调色分类、通道和蒙版选择。 |
| 工具菜单开合 | 用一个锚定在参数区标题的临时菜单。选择、点外部或系统返回会关闭菜单。点外部时关闭即可，避免同一次点击同时调整参数。 |
| 顶部 × / 系统返回 | × 直接取消本次草稿，回到同一张照片。系统返回优先关闭当前菜单或面板，再执行相同取消逻辑。 |
| 完成 | 将全局调色、蒙版和几何一起保存。保存中显示「保存中…」，屏蔽重复提交、退出及参数修改。成功回到同一张预览。失败留在编辑页，草稿和历史可继续使用，允许重试。 |
| 撤销 / 重做 | 一个会话一份历史，快照使用 `PhotoEdits`。一次滑杆手势、曲线拖动、蒙版笔触、裁切拖动、选比例、旋转或复位各记一步。仅在参数确实变化时记录。撤销后的新改动清空重做；工具切换与按住原图对比不写入历史。 |
| 编辑更多 | 保留「复制调色参数」「粘贴调色参数」「复位全部调色及蒙版」的既有语义。复制和粘贴包含调色与蒙版，几何由旋转裁切工具负责。粘贴和复位走当前草稿及撤销历史。 |
| 系统中断 | 前后台切换和配置变更期间继续保留活跃会话。进程被回收后恢复已保存版本；未提交草稿不会随生命周期回调写盘。 |

对比按钮放在照片区右下，按住显示原图，松手或手势取消时恢复。为便于判断调色差异，建议对比沿用当前裁切和旋转。裁切编辑期间优先保障裁切手势，可隐藏对比入口。参数面板高度改变时保留观察中心并约束在当前画布内，菜单开合本身不重置缩放。

### 3.2 统一下拉菜单

- 收起态显示当前项。调色显示「调色 · 曲线」或其它分类名，另外两项显示「蒙版」和「旋转裁切」。48dp 可点击高度，尾部折叠图标随开合改变方向。
- 菜单优先朝照片区展开，宽 286dp，遇窄屏按可用宽度缩小。圆角 18dp，内边距 8dp。每项触控高度至少 48dp。菜单以当前入口为锚点，系统安全区不足时约束高度，菜单内容可滚动。窄屏或大字号下，两列标签放不下时改为单列。参数区不参与重排。
- 调色分组采用两列，阅读顺序为光线、曲线、色彩、混色、效果、分级、细节；下方分隔线后为蒙版、旋转裁切。选中项使用浅底和勾选，辅助功能同时提供选中语义。点任一项立即切换、收起菜单；切换不提交草稿。
- 蒙版层选择、新建蒙版、曲线通道等是工具内部控件。编辑工具始终从同一个菜单进入。

### 3.3 调色与曲线

- 普通参数区高约 244dp。标题下可垂直滚动，首屏约三项。每项上行左名称、右数值，下一行是滑轨。保持当前参数范围、精度、零点和手势映射。省略底部说明文案。
- 混色颜色选择留在工具内；分级用「阴影／中间调／高光／全局」局部选择器，每次显示该组滑杆。保留原有分级共享参数与黑白状态下的控制可用性。
- 曲线画布居中，`宽 = 高 = min(可用宽度, 320dp)`。标准 360dp 及以上宽度时目标为 320dp；极短屏优先使用自适应布局，禁止以压扁画布解决高度不足。控件为 RGB、红、绿、蓝，保留现有加点、拖动、删除中间点、当前通道复位、端点约束与输入/输出坐标。
- 基础网格为 4 × 4。控制点可视半径约 5dp，命中半径 24dp。拖动中的坐标显示使用固定高度的底部行，以免拖动时画布重排。
- 颜色提示绘在网格下层。令 `x` 从左到右、`y` 从上到下归一化，渐变沿左上至右下，透明度在 `x + y = 1` 的中性斜线上为 0，越靠两端越明显，端点 alpha 建议 0.28。颜色提示依靠渐变；通道名仍保留。

  | 通道 | 左上 | 右下 |
  | --- | --- | --- |
  | RGB | `#F3F3F3` | `#303237` |
  | 红 | `#F18A86` | `#52C6CA` |
  | 绿 | `#84C49A` | `#CF85BC` |
  | 蓝 | `#82AEE7` | `#D9BE65` |

### 3.4 蒙版

- 面板目标高度 344dp。统一菜单下面是蒙版缩略图与名称、新建按钮和「调整参数」/「编辑范围」动作。保留多蒙版选择和空状态的「新建蒙版」。
- 新建提供画笔、线性渐变、径向渐变，创建后选中新蒙版并进入范围。范围参数显示现有功能：画笔的大小、羽化、不透明度；线性的羽化、不透明度与画面内控制点；径向的旋转、羽化、不透明度。保留已有的添加、减去、拖动与范围几何能力。
- 点「调整参数」进入所选层的局部调色，按钮改为「编辑范围」。局部分类通过参数区内紧凑选择入口访问，保持现有支持的分类与参数。此时默认隐藏范围覆盖，绘制手势暂停，选择其它层时按该层状态刷新。
- 重命名、复制、反转范围、显示或隐藏效果、删除放在蒙版选项菜单。删除蒙版可撤销。蒙版调整只更新 `MaskLayer.tone`。原型中的部分滑杆为视觉演示，开发以现有模型与渲染结果为准。

### 3.5 旋转裁切

- 同一参数区标题为「旋转裁切」。下面依次放左旋 90°、右旋 90°、「复位」，自由旋转刻度与一位小数角度，以及比例图标横向列表。参数区目标高度 248dp；比例卡宽约 60dp、高 66dp、间距 8dp。
- 自由旋转沿用 `−45° 至 +45°` 的角度范围。零点可见，步长或读数精度 0.1°。左右 90° 使用现有几何变换，裁切比例与输出尺寸跟随实际方向更新。「复位」只复位几何。
- 比例顺序为自由、原图、1:1、4:3、3:4、3:2、2:3、16:9、9:16、4:5、5:4。每项同时显示比例轮廓和名称。自由项用虚线，原图图标按源图在当前方向下的有效比例绘制。固定比例保持锁定，自由项可任意拖动。支持四角、边缘和框内拖动，裁切框受有效图像范围约束。
- 顶栏显示预计像素尺寸 `宽 × 高`，尺寸计算与导出共用 `PhotoGeometry.outputSize`。切换工具再回来时保持已选比例和几何结果，撤销几何时同步刷新比例选中状态。

大字体下可允许参数名折行，滑杆保持独立整行。TalkBack 按顶栏、照片及参数区的视觉顺序浏览，读取操作名、参数值、选中与禁用状态；图标的装饰性路径不单独获得焦点。

| 阶段 | 文件及现有入口 | 改动 |

| 5. 浏览与临时面板 | `ui/GridScreen.kt`、`ui/PhotoPagerScreen.kt`、`ui/DeleteConfirmationDialog.kt`、`ui/AppRoot.kt` | 统一图库和预览样式；复制、粘贴、复位移动至编辑；照片信息、导出、删除采用共享底部面板。保留现有的 `requestExport`、`confirmDeletion` 和对应授权 launcher。 |

从滑杆、曲线、蒙版笔触和裁切拖动接收开始/结束事件，离散命令走同一历史入口。撤销、取消、切图及完成时，让已有渲染调度接收最终快照，核对滞后的预览任务不会覆盖该帧。移除面板自身的撤销栈之前，先确认其它调用方是否还使用独立面板。

## 6. 联调与验收

| 编号 | 操作 | 通过条件 |
| --- | --- | --- |
| E01 | 从照片预览点编辑，展开调色菜单 | 预览底栏隐藏；同一菜单能看到七个调色分类及蒙版、旋转裁切；开合前后图片与参数区位置相同。 |
| E02 | 调曲线，切蒙版，切旋转裁切，再回曲线 | 三个工具共用同一入口；前面的编辑保留；画面底部无遮挡。 |
| E03 | 改调色、画蒙版、改比例或旋转，逐次撤销与重做 | 按操作顺序跨工具还原；持续拖动只记一步；再编辑时清空重做。 |
| E04 | 给已有编辑的照片增加三类修改后点 ×，另一次用系统返回取消 | 预览恢复进入前结果，重新进编辑和导出得到原有已保存版本。菜单展开时系统返回先关菜单。 |
| E05 | 同时修改三类工具，点完成，再重启应用与导出 | 编辑结果完整持久化，预览及导出与最终草稿一致。模拟写入失败后可原地重试，失败期间无重复提交。 |
| E06 | 红、绿、蓝和 RGB 通道逐项操作 | 曲线为正方形，通道渐变方向正确，可加点、拖动、删除及复位；曲线区域拖动不会触发外层滚动。 |
| E07 | 新建画笔、线性、径向，切换范围与调整，复制、删除、撤销蒙版 | 加高面板中滑杆完整可用；切换与复制对应正确层；局部参数只改变蒙版作用区；无蒙版时能直接新建。 |
| E08 | 横图、竖图和已旋转照片逐一测比例、拖角及边、左右 90°、自由旋转 | 图标比例正确；裁切框受边界约束；预览尺寸和导出 JPEG 像素尺寸一致。 |
| E09 | 打开本地照片与 OTG 照片，执行单张与多选删除，模拟系统拒绝 | 授权前不修改原片；拒绝、部分成功和完全成功对应正确反馈及索引结果。 |
| E10 | CR3 与其它照片分别查看导出面板并导出 | 仅 CR3 可选内嵌 JPEG。两种路径使用各自的编辑与尺寸规则，导出失败给出真实结果。 |
| E11 | 测试 320dp、360dp、390dp 竖屏、横屏、字体缩放 1.3×、深浅色及 TalkBack | 菜单项可达，参数与按钮不重叠，曲线保持方形，系统安全区正确。 |
| E12 | 快速切图和切工具，连续拖动，进入后台再返回 | 当前图像不会被旧预览覆盖；滑杆反馈连续，解码与扫描不重复触发；未提交草稿不落盘。 |

回归入口为 `python3 scripts/verify_host_checks.py` 及 Android 的 `PhotoGeometryInstrumentedTest`。合并前在真机执行上表，尤其覆盖 API 28 的写入授权和 API 31+ 的删除授权。交接原型的浏览器验证不能替代真机验收。
